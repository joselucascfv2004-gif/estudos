### Módulo é distância

O módulo de um número, |x|, é a **distância** entre esse número e o zero na reta. Como distância nunca é negativa:

- |5| = 5 e |−5| = 5.
- |0| = 0.

Em forma de regra: |x| = x quando x ≥ 0, e |x| = −x quando x < 0. O "−x" do segundo caso é positivo, porque x é negativo.

### Distância entre dois números

A distância entre a e b na reta é **|a − b|** (a ordem não importa). Essa leitura resolve muita questão sem conta:

- |x − 3| é a distância entre x e 3.
- |x + 2| = |x − (−2)| é a distância entre x e −2.

> **Exemplo resolvido.** A mínima foi −4 °C e a máxima 9 °C. A variação é |9 − (−4)| = **13 °C**.

### Equações modulares

**|A| = k, com k > 0**, tem dois casos: A = k ou A = −k.

> **Exemplo resolvido.** |x − 3| = 4
> x − 3 = 4 ⇒ x = 7, ou x − 3 = −4 ⇒ x = −1. **S = {−1, 7}**.
> Pela ideia de distância: os pontos a 4 unidades de 3 são 7 e −1.

Atenção:

- **|A| = negativo** não tem solução, porque módulo nunca é negativo.
- **|A| = 0** só tem uma solução: A = 0.
- Se o lado direito tem x, como em |2x − 3| = x + 3, resolva os dois casos e **confira** se o lado direito ficou maior ou igual a zero.

### Inequações modulares

- **|A| < k** (perto): −k < A < k. A resposta é um intervalo "dentro".
- **|A| > k** (longe): A < −k ou A > k. A resposta são duas partes "fora".

> **Exemplo resolvido.** Uma peça deve medir 50 mm, com erro máximo de 0,2 mm.
> |x − 50| ≤ 0,2 ⇒ 49,8 ≤ x ≤ 50,2.

### Raiz de quadrado vira módulo

√(x²) = |x|, porque a raiz quadrada nunca dá negativo. Por exemplo, √((−6)²) = √36 = 6.

Isso ajuda a simplificar expressões como √(x² − 6x + 9) = √((x − 3)²) = |x − 3|.

### Gráfico da função modular

O gráfico de f(x) = |x| é um **"V"** com o bico na origem. Mexendo na fórmula, o V se desloca:

- f(x) = |x − a|: o bico vai para x = a.
- f(x) = |x| + b: o V sobe b (ou desce, se b for negativo).
- f(x) = |x − 2| + 1: bico em (2, 1).

A imagem de |x| + b é [b, +∞), porque o menor valor de |x| é zero.

> **Exemplo resolvido.** A reta y = 4 corta y = |x| em (−4, 4) e (4, 4). A região entre os dois gráficos é um triângulo de base 8 e altura 4: área **16**.

### Soma de distâncias: um truque de prova

f(x) = |x − a| + |x − b| é a soma das distâncias de x até a e até b. Para qualquer x entre a e b, essa soma é exatamente |a − b|, e esse é o menor valor possível.

Com três pontos, como |x − 1| + |x − 6| + |x − 13|, o mínimo acontece no ponto do meio (x = 6): 5 + 0 + 7 = **12**. Esse é o raciocínio de "onde construir um posto para atender três casas numa estrada".
