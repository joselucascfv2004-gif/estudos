### A unidade imaginária

Não há número real cujo quadrado seja −1. Os matemáticos criaram um: **i**, com **i² = −1**. Com ele, toda equação do 2º grau tem solução.

Um número complexo tem a forma **z = a + bi**: a é a parte real, b a parte imaginária.

Potências de i se repetem de 4 em 4: i⁰ = 1, i¹ = i, i² = −1, i³ = −i. Para iⁿ, use o resto da divisão de n por 4: i²⁰²³ = i³ = −i (2023 dá resto 3).

### Operações

- **Soma:** real com real, imaginário com imaginário.
- **Produto:** distributiva, lembrando que i² = −1. (2 + 3i)(1 − i) = 2 − 2i + 3i − 3i² = 2 + i + 3 = **5 + i**.
- **Conjugado** de a + bi é a − bi. z · z̄ = a² + b², sempre real.
- **Divisão:** multiplique em cima e embaixo pelo conjugado do denominador.

### Plano de Argand-Gauss

O complexo a + bi é o ponto (a, b).

- **Módulo:** |z| = √(a² + b²), a distância até a origem.
- **Argumento:** o ângulo com o eixo real.
- **Forma trigonométrica:** z = |z| · (cos θ + i·sen θ). Para multiplicar, multiplique os módulos e **some os ângulos**.

### Polinômios

P(x) = aₙxⁿ + … + a₁x + a₀. O grau é o maior expoente.

- **Valor numérico:** P(2) é só substituir x = 2.
- **Raiz:** número que zera o polinômio.
- **Teorema do resto:** o resto da divisão de P(x) por (x − a) é **P(a)**. Se P(a) = 0, então (x − a) é fator.

> **Exemplo resolvido.** Resto de P(x) = x³ − 2x + 5 dividido por (x − 2):
> P(2) = 8 − 4 + 5 = **9**.

**Dispositivo de Briot-Ruffini:** forma rápida de dividir por (x − a), usando só os coeficientes.

### Relações de Girard

Para ax³ + bx² + cx + d = 0, com raízes r₁, r₂, r₃:

- soma: r₁ + r₂ + r₃ = −b/a;
- soma dos produtos dois a dois: c/a;
- produto: r₁ · r₂ · r₃ = −d/a.

Um polinômio de grau n tem exatamente **n raízes complexas** (contando repetições). Se os coeficientes são reais, as raízes não reais vêm em pares conjugados.
