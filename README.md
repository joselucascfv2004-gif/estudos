# Projetos

Este repositório guarda dois projetos separados:

- 📚 [`estudos/`](estudos/README.md) — app de questões no estilo Duolingo para ENEM, vestibulares
  militares e concursos.
- 🎬 [`tiktok/`](tiktok/README.md) — canal de TikTok com histórias narradas por voz de IA sobre vídeos
  de fundo (jogos, vídeos satisfatórios), com o objetivo de chegar a 10 mil seguidores e entrar no
  Programa de Recompensas para Criadores.
